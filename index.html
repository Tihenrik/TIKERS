Configure sua chave da API do Google Maps

Este app precisa de uma chave da Google Maps JavaScript API (com as bibliotecas places e geometry habilitadas) para carregar o mapa.

Abra o arquivo diligencias-mapa.html em um editor de texto, localize a linha:

const GOOGLE_MAPS_API_KEY = "SUA_CHAVE_AQUI";

e substitua pela sua chave. Depois, salve e abra o arquivo novamente no navegador (ou hospede em um servidor/GitHub Pages).
